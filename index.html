Server Down? Follow These Steps

Go in order. Check the website again after every step.

1Check the website

Open slothhost.online on your phone.

Loads fine? Nothing to do. You're done.

Not loading? Go to Step 2.

Open slothhost.online

2Check the electricity

Is the power off in the house or at the server area?

If yes, turn the power back on (check the distribution board / DB switches too).

Then check the website again.

3Check the WiFi / router

Is the WiFi router on?

If it is off, turn it on. Then wait 2 to 3 minutes for it to start up.

Then check the website again.

4Check the ethernet lights

After waiting, look at the router. You should see 2 blue ethernet connection lights.

2 blue lights? Good. Check the website.

Only 1 blue light? Go to Step 5.

5Check the laptop server

Go to the laptop server. Is it powered off?

If yes, turn it back on. Wait a few minutes, then check the website again.

✓All 3 checked?

Electricity, WiFi, and laptop all on? The server will fix itself automatically.

Give it a few minutes, then check slothhost.online again.

Still down after waiting? Contact Haris.
